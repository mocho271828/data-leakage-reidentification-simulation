# Gate: 依存の利用と出力の保護

## 目的

既存のツールで処理を再現し, 再実行や失敗時も以前の実験結果を保護する.

## 判定条件

- [ ] RustのCLI・Parquet入出力には既存のclap・Polarsを使い, 照合の集合演算にはDuckDBを使う. これらに代わる依存の追加時は必要な理由を記す.
- [ ] データセットを生成するRustコマンドは新しい出力先を受け取り, 既存ディレクトリへの出力を拒否する.
- [ ] 個々のRustコマンドは一時ディレクトリでデータを作り, 生成完了後に出力先へ移動する.
- [ ] DuckDB CLIを利用できる環境で `cargo test --locked` が通る.

## 不合格条件

- [ ] 再実行により既存のデータセットが置換される, または処理に失敗したデータセットが完成品として公開される.

## 判定

YES / NO
