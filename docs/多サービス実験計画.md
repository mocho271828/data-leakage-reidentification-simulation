# サービス数と共通登録者数を同時に変える実験計画

2026年11月25日。新規サービスの事故で無作為に選ばれた10人全員を正しく照合できる確率について、どの登録配置でも80%以上となる条件、配置によって80%をまたぐ条件、どの配置でも80%未満となる条件を調べる。

## 名簿と採点

新規サービスの架空登録者を1万人、過去の各サービスの架空登録者を1,000人とする。新規サービスの登録者を同じ人として数えられる、サービス共通で一意かつ不変の照合用メールを仮定する。過去に漏えいした行はすべて本人と対応づいている。過去の各社には1回ずつ事故があり、その1,000人からちょうど120人、240人、または1,000人が等確率で漏えいする。各事故の抽選は独立で、サービス内では非復元抽出する。新規の10人は過去の事故とは独立に非復元抽出する。各人が過去に1回以上登場すれば正答、それ以外は保留とし、10人全員を正答した事故を成功と数える。

今回の名簿は全国架空人口の属性を必要としない。各社1,000人のうち新規サービスと重ならない枠も漏えい抽選の分母に含める。それらの人のサービス間の重なりは、この照合規則での新規10人の結果に影響しない。これまでの2サービス実験とはメール再利用率、登録者数、事故履歴が異なる。

## 動かす条件

- 過去のサービス数は1、2、3、5、10、20、50、100、200、500、1,000社とする。
- 各社と新規サービスの共通登録者数は、各社同数の0、10、25、50、100、250、500、1,000人とする。各社同数の組み合わせは88通り。別に平均100人のまま半数の会社を50人、半数を150人とする。奇数なら中央の1社を100人とし、1社の条件は均等条件と重複するため除く。
- 過去2社以上に登録した新規サービスの実人数を $D$ とする。集計だけで判断できる範囲を調べるときは、各組み合わせで実現できる**すべての整数**を調べ、同じ判定が続く範囲を1行にまとめる。残る配置には確率分布を仮定しない。

## 計算と反復

1. **全記録を使える条件**では、過去の少なくとも1社に登録した実人数の最小値・最大値を求める。それぞれから、10人の非復元抽出による全員正答確率を計算する。下限が80%以上なら到達を保証、上限が80%未満なら未達、それ以外は配置に依存すると判定する。
2. **12%・24%漏えい**では、全登録配置に対する上界と、実現できる配置の確率の下界を使って同じ条件を判定する。得られた不等式だけでは80%のどちら側か決まらない場合は、そのまま記録する。各社1,000人全員が新規サービスに登録する条件では、1万人を1,000人ずつ10群に分け、各社に1群ずつ循環順に割り当てる。この配置に限り、整数のサービス数1〜1,000の中から80%に達する最小のサービス数を厳密に求める。
3. **独立した計算法で照合するための反復**では、各配置で10,000回の新規事故を抽選する。事故シードは8,037,000〜8,046,999。同じ反復では10人と各社の無作為順位を3つの漏えい率で共有する。10人全員の成功件数・確率と点ごとの両側95% Wilson信頼区間、正答人数の平均を記録する。各社の順位を新規対象者についてだけ抽選しても、同じ会社の固定人数抽出による人どうしの依存を保てる。

反復用の配置は次のとおりとする。

| 比較 | 配置 |
|---|---|
| 延べ1万人のまま会社を増やす | 10社×1,000人、20社×500人、100社×100人、1,000社×10人、100社で50人・150人を半数ずつ。各条件で $D=0$ と $D=20$ を使い、後者は過去に登場し得る実人数が最小・最大の2配置を作る。 |
| 延べ人数を増やす | 各社1,000人で20、50、100、130、140、150、200、280、290、300、500、1,000社。1,000人の群を順番に割り当てる配置と、全社が同じ1,000人を共有する配置を比較する。 |

全記録の上下限は小さい全名簿の列挙と照合する。10群の厳密計算は小さい名簿・漏えいの全列挙と照合し、代表配置の反復値とも比較する。80%との差を判定する際は、表示用に丸める前の値を使う。

## 厳密境界を求めた後の追加確認

12%・24%の厳密計算で得た境界の前後に当たる139、140、298、299社を選ぶ。別の事故シード9,100,000〜11,099,999を使い、各配置をちょうど200万回抽選する。新規10人、漏えい人数、均等な循環配置、信頼区間の計算法をそろえ、途中の結果による反復の追加は行わない。この4点は最初の39配置とは別に報告する。
