# Gate: 依存の利用と出力の保護

## 目的

既存のツールで処理を再現し, 再実行や失敗時も以前の実験結果を保護する.

## 判定条件

- [x] RustのCLI・Parquet入出力には既存のclap・Polarsを使い, 照合の集合演算にはDuckDBを使う. これらに代わる依存の追加時は必要な理由を記す.
- [x] データセットを生成するRustコマンドは新しい出力先を受け取り, 既存ディレクトリへの出力を拒否する.
- [x] 個々のRustコマンドは一時ディレクトリでデータを作り, 生成完了後に出力先へ移動する.
- [x] DuckDB CLIを利用できる環境で `cargo test --locked` が通る.

## 不合格条件

- [ ] 再実行により既存のデータセットが置換される, または処理に失敗したデータセットが完成品として公開される.

## 判定

YES

`Cargo.toml`, `src/main.rs`, `src/evaluation.rs` で依存と一時出力を確認した. 空でない既存ディレクトリへの生成を試し, コマンドが失敗し元のファイルが残ることを確かめた. 入力のない投影が失敗したときも指定出力先は作られなかった. `DUCKDB_BIN` にDuckDB CLIを指定して `cargo test --locked` を実行し, 単体12件と統合2件が通った.
